TASDIK RUNNER 3D
=================
A standalone 3D endless runner prototype.

Run:
1. Open index.html in a modern browser with internet access.
2. Tap TAP TO PLAY.
3. Swipe left/right to change lanes, up to jump, down to slide.
4. Keyboard arrows/WASD also work on desktop.

Note: Three.js is loaded from jsDelivr, so an internet connection is required.
This is an original Tasdik Runner implementation, not a copy of Subway Surfers assets.
